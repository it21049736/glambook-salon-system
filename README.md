# GlamBook - Beauty Salon Appointment Booking System

GlamBook is a Java web application for a beauty salon. Customers can register, browse services
and stylists, book appointments, pay and leave reviews. Admins manage users, services, stylists,
payments and reviews.

All data is stored in plain `.txt` files (no database).

## Tech stack
- Java 17, Maven (war)
- Jakarta Servlets, JSP, JSTL
- Apache Tomcat 10
- Bootstrap 5
